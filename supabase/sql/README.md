# سجل تعديلات قاعدة البيانات

الملفات دي **اتشغّلت فعلًا** على قاعدة الإنتاج من محرر SQL في Supabase.
محفوظة هنا كسجل، مش عشان تتشغّل تاني.

- الملفات اللي اسمها `DIAGNOSE` **قراءة فقط** — بتفحص ولا بتغيّر حاجة،
  وتشغيلها تاني آمن في أي وقت.
- الباقي **بيغيّر** القاعدة. تشغيله تاني غالبًا هيفشل بخطأ «موجود
  بالفعل»، وده المطلوب.

## ناقص

التعديلات اللي اتشغّلت **قبل ملف 24** (تقريبًا من 11 لـ 23) مش محفوظة
هنا — اتشغّلت قبل ما نبدأ نسجّل. أثرها موجود في القاعدة، ووصفها
الحقيقي بيتقرا من القاعدة نفسها بملف 38، مش من هنا.
